# AI 기반 LAN 보안 플랫폼: ARP·DHCP 공격 탐지 및 자동 차단

컴퓨터네트워크 2026-2 팀 프로젝트 (9~15주차) · 팀 **파이브 가이즈**

주제 제출문은 [PROPOSAL.md](PROPOSAL.md)에 있습니다.

## 해결하려는 문제

ARP와 DHCP는 인증 절차가 없습니다. 그래서 같은 LAN 안의 공격자가 ARP 스푸핑이나 가짜 DHCP 서버만으로 중간자 공격(MITM)을 할 수 있습니다. 일반 사용자는 이런 공격을 알아채기 어렵습니다.

## 접근 방법

1. 격리된 가상 LAN(VM, Mininet)에서 **ARP 스푸핑부터** 재현하고, 이후 가짜 DHCP 서버, 웹(DNS·HTTP) 공격으로 단계적으로 넓힙니다.
2. Scapy로 패킷을 실시간 캡처하고 ARP, DHCP, 플로우 특징을 추출합니다.
3. **규칙 기반 탐지기**와 **AI 모델**(공개 데이터셋 Kitsune Network Attack으로 학습하고, 실험망 데이터로 추가 학습)로 공격을 판정합니다.
4. 공격이 탐지되면 웹 기반 보안 플랫폼(대시보드)과 디스코드로 경보를 보내고, **SDN 컨트롤러(Ryu)가 공격자 포트를 자동으로 차단**합니다.
5. 규칙, AI, 혼합 방식의 탐지율, 오탐률, 탐지 시간을 비교합니다.

## 탐지 대상 공격

| 공격 | 계층 | 관련 실습 |
|---|---|---|
| ARP 스푸핑 / 중간자 공격 | L2 | w07 |
| MAC 플러딩 (CAM 테이블 고갈) | L2 | w07 |
| 가짜 DHCP 서버 / DHCP 고갈 | L3 | w05 |
| 네트워크·포트 스캔 | L3/L4 | w04 |
| SYN flood | L4 | w04 |
| DNS 스푸핑 (확장 목표) | L7 | w03 |

## 기술 스택

Python 3, Scapy, Mininet, Ryu, scikit-learn, SHAP, Streamlit, Wireshark, Ubuntu VM

## 안전 수칙

- 모든 공격 실험은 **격리된 가상 환경(VM, Mininet) 안에서만** 수행합니다.
- 학교망, 공용 와이파이, 타인의 네트워크에서는 절대 실행하지 않습니다.
- 캡처 파일을 올리기 전에 실제 MAC, IP 등 개인 식별 정보를 제거합니다.
